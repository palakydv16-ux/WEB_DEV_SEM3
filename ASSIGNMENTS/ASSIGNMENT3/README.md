# Assignment 3 - Portfolio using Express.js

## Objective

Create a portfolio using HTML and CSS and display it through an Express.js server.

## Technologies Used

- HTML
- CSS
- Node.js
- Express.js

## Project Structure

- `index.js` - Express server
- `public/index.html` - Portfolio webpage
- `public/style.css` - Portfolio styling

## Installation

Install Express:

```bash
npm install express
