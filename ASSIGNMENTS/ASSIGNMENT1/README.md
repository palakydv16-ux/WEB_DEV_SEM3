# Student Record Management System

This project is a Node.js application for managing student records.

## Technologies Used

- Node.js
- HTTP module
- FS module
- HTML
- JSON

## Features

- Student registration form
- Add student records
- Store student data in students.json
- Display student records
- HTTP server running on port 3000

## Routes

### Home
http://localhost:3000/

### Student Records
http://localhost:3000/students

## How to Run

Open the terminal in the ASSIGNMENT1 folder and run:

node server.js

Then open:

http://localhost:3000
